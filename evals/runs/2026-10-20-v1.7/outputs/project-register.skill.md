## 1. 范围与角色

### 1.1 角色
- **企业项目管理员**：本功能唯一角色。只能维护（查看、新增、编辑、暂存、提交）**本企业**的项目。

### 1.2 范围内能力（P01）
- 项目**列表**、**详情**、**新增**、**草稿编辑**、**暂存**、**提交**。
- 明确排除：**审批**、**导出**（P01「无审批与导出」）。不自行增加撤回、作废、复制等能力。

### 1.3 对象与状态
- 对象：企业项目（Project）。
- 类型（P02）：{内部, 外包}。
- 状态（P06）：由暂存/提交动作产生，用户不可手工设置。枚举：
  - 草稿：由「暂存」产生；
  - 已提交：由「提交」产生。
- 状态与动作对应关系：暂存→草稿；提交→已提交。已提交后全部业务编辑字段只读，不再有编辑入口（无撤回/作废）。

## 2. 页面与功能设计

### 2.1 页面划分
- **项目列表页**：含查询区 + 列表 + 「新增」入口（P01、P06）。
- **项目详情页**：只读展示 + 草稿态「编辑」入口（P01、P06）。
- **项目表单页**：新增与草稿编辑共用同一表单，提供「暂存」「提交」两个动作（P01、P05）。
- 说明：新增与草稿编辑字段、校验一致，仅预填内容与入口不同，故共用表单，不拆页（页面组合规则：同一对象仅入口不同时共用）。

### 2.2 项目列表页（查询区字段细则）

查询条件（多条件 AND 组合，全部可选；空条件 = 本企业全部项目）：

| 字段 | 用途/控件 | 值域/来源 | 默认值 | 匹配方式 |
|---|---|---|---|---|
| 名称 | 筛选，文本输入 | 任意文本 | 空（不筛选） | 候选：模糊匹配（待评审，见附录 A） |
| 类型 | 筛选，单选下拉 | 内部 / 外包 | 空（全部） | 精确匹配 |
| 状态 | 筛选，单选下拉 | 草稿 / 已提交 | 空（全部） | 精确匹配 |

- 重置行为：清空全部条件，恢复默认（显示本企业全部项目）。

### 2.3 项目列表页（列表展示列）

| 列 | 业务含义 / 单位 / 枚举 | 来源 | 缺值展示 |
|---|---|---|---|
| 名称 | 项目名称 | 项目数据 | — |
| 类型 | 内部 / 外包 | 项目数据 | 草稿可缺 → 展示为空（—） |
| 预算 | 预算金额，单位万元，两位小数 | 项目数据 | 缺失展示空（—）；值 0 展示 `0.00`（缺失 ≠ 0，见 P03） |
| 起止日期 | 开始日期 至 结束日期 | 项目数据 | 草稿可缺 → 对应项展示空（—） |
| 状态 | 草稿 / 已提交 | 由暂存/提交动作产生 | — |

- 列表**不显示服务商**（P06：服务商仅在详情显示）。
- 行操作：点击行/名称进入详情。
- 列表排序：候选 = 按创建时间倒序（待评审，见附录 A）。
- 列表分页：待决定（页面实现细节，见附录 A）。

### 2.4 项目详情页（字段细则）

| 字段 | 展示内容 | 读写 | 说明 |
|---|---|---|---|
| 名称 | 项目名称 | 只读 | — |
| 类型 | 内部 / 外包 | 只读 | — |
| 预算 | 万元，两位小数 | 只读 | 缺失展示空（—），非 `0.00` |
| 开始日期 | 日期 | 只读 | — |
| 结束日期 | 日期 | 只读 | — |
| 服务商 | 目录中服务商名称 | 只读 | 内部项目：空（—）；外包项目：显示所选服务商（P06 详情额外显示服务商） |
| 状态 | 草稿 / 已提交 | 只读 | 由动作产生 |

- 详情页行为：
  - 状态 = 草稿：提供「编辑」入口，进入草稿编辑（共用表单，预填当前值）。
  - 状态 = 已提交：无编辑入口，全部业务编辑字段只读。

### 2.5 项目表单页（新增 / 草稿编辑，字段细则）

| 字段 | 控件 | 暂存必填 | 提交必填 | 校验与规则 | 提交后 |
|---|---|---|---|---|---|
| 名称 | 文本输入 | **是** | 是 | 非空（暂存唯一要求，P05） | 只读 |
| 类型 | 单选：内部 / 外包 | 否 | 是 | 必须选中一项（P05） | 只读 |
| 预算 | 数字输入（万元） | 否 | 是 | ≥ 0；最多两位小数；缺失 ≠ 0（P03） | 只读 |
| 开始日期 | 日期控件 | 否 | 是 | 不强制默认当天（P04） | 只读 |
| 结束日期 | 日期控件 | 否 | 是 | 不得早于开始日期（P04） | 只读 |
| 服务商 | 关联选择（本企业已有服务商目录） | 否 | 条件必填 | 外包 = 必填；内部 = 不要求（P02） | 只读 |

补充说明：
- **服务商选择**：从「本企业已有服务商目录」选择，按**稳定身份**关联、显示名称（多条同名服务商不得任意取首项）。
- **类型 = 内部**时：服务商不要求、不参与校验；是否仍显示服务商选择控件为设计建议（候选：内部类型隐藏/禁用服务商选择）。
- 服务商目录本身为既有数据，其维护入口**不在本轮范围**（P02 仅要求「从本企业已有服务商目录选择」）。

## 3. 动作细则

### 3.1 暂存（P01、P05）
- 触发：表单页点「暂存」。
- 适用条件：新增或草稿编辑均可。
- 输入：当前表单各字段。
- 规则：仅校验**名称非空**；其余字段不校验、可留空。
- 结果：保存为草稿，状态 = 草稿；返回列表或详情（返回去向为候选，待评审）。
- 失败：名称为空 → 提示「名称必填」，定位名称字段，保留已输入内容。

### 3.2 提交（P01、P05）
- 触发：表单页点「提交」。
- 适用条件：新增或草稿编辑均可（D3：无需先暂存）。
- 输入：当前表单各字段。
- 规则（全部校验，任一失败即整体拒绝）：
  1. 名称非空；
  2. 类型已选；
  3. 预算已填且 ≥ 0、最多两位小数；
  4. 开始日期、结束日期已填；
  5. 结束日期 ≥ 开始日期；
  6. 类型 = 外包 → 服务商必填；类型 = 内部 → 服务商不要求。
- 结果：状态 = 已提交；**全部业务编辑字段只读**，不再提供编辑入口。
- 失败：任一必填/校验失败 → 定位到具体字段并提示原因，保留已输入内容，状态不变。

### 3.3 草稿编辑（P01）
- 触发：列表进入草稿详情 → 「编辑」。
- 适用条件：状态 = 草稿。
- 结果：打开共用表单，预填当前值；可「暂存」或「提交」。
- 已提交项目无编辑入口（P05）。

### 3.4 状态流转
```
[新增] ──暂存──▶ [草稿] ──提交──▶ [已提交]
   │                │
   └──────提交──────┘(直接提交，D3)
[草稿] ──草稿编辑──▶ [草稿](仍为草稿)
[已提交] ──(无编辑)──▶ 只读
```

## 4. 业务规则细则

### 4.1 预算（P03）
- 单位：万元。
- 精度：最多两位小数。
- 范围：≥ 0（0 合法）。
- 缺失 ≠ 0：空值（未填写）在展示、查询中与数值 0 区分；草稿可缺失，提交不可缺失。
- 小数位处理方式：候选 = **拒绝**多于两位小数的输入（而非四舍五入），待评审（见附录 A）。

### 4.2 日期（P04）
- 结束日期 ≥ 开始日期（等于允许，早于不允许）。
- 日期输入不强制默认当天（新增/草稿编辑时日期控件不预填今天）。

### 4.3 服务商条件（P02）
- 外包：必须从本企业已有服务商目录选择服务商。
- 内部：不要求服务商。
- 类型切换（外包→内部）：见 D1（候选：清空服务商）。

### 4.4 状态（P06）
- 状态仅由「暂存」「提交」动作产生，用户不可手工设置。

## 7. 缺口与后续工作

### 7.1 材料或业务决定缺失（需补充事实/选择）
- **D1 类型切换旧服务商处理**（影响 P02）：需决定「清空」或「保留但不生效」。解除后可确定服务商条件必填与详情展示的完整行为。
- **D2 状态枚举展示用语**（影响 P06）：语义已确定，仅用语需确认。
- **D3 提交是否需先暂存**（影响 P01/P05）：影响提交入口与最小操作步骤。
- **服务商目录数据来源与可得性**（影响 P02）：目录已知存在但具体源系统/字段未定；需确认目录为空、多条同名时的选择行为（本 PRD 已要求按稳定身份关联）。

### 7.2 本轮设计遗漏或矛盾
- 无已识别的自相矛盾；P02 的未决点已显式标注，未以「后续补字段」代替。

### 7.3 下一阶段规格（本轮深度之外）
- 名称长度/唯一性、列表分页与默认排序、名称筛选匹配方式、日期控件具体格式、预算小数位处理方式等**页面实现细节**（见附录 A）——本轮不擅自加约束，属原型/详细设计阶段确认项。
- 完整视觉原型、数据库表结构与 API 规格：**不属本 PRD 范围**（交付要求明确不设计数据库和 API）。

### 7.4 可先行范围
- 列表/详情/表单字段结构、必填与校验、状态流转、权限范围均已可评审；可据此开展原型设计与字段级详细设计。仅「类型切换旧服务商处理」一个分支需业务确认后方可定稿。

## 附录 B：术语与解释

- **维护（P01）**：本 PRD 将「维护」解释为对项目的查看与增改（列表、详情、新增、草稿编辑、暂存、提交）均限本企业。若「维护」仅指写操作、查看可跨企业，则需重定列表/详情的可见范围（属 D4 的另一种解释，会改变权限结果）。
- **缺失 ≠ 0（P03）**：空值（未填）与数值 0 是两个不同状态，展示时分别以「空（—）」与 `0.00` 呈现。
